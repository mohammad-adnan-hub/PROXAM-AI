01 Raft Protocol & Log Replication
5 Points
In a standard Raft consensus cluster comprising 5 distinct server nodes, what is the absolute minimum number of node responses required by the leader to successfully commit an entry to the replicated log?
A 2 nodes (Leader + 1 Follower)
B 3 nodes (A strict majority quorum)
check Correct Key
C 4 nodes (Supermajority)
D 5 nodes (Unanimous consensus)

Ongaro & Ousterhout (2014) Quorum Rule:

Raft requires a majority of cluster members floor(N/2) + 1 to safely commit an entry. In a 5-node cluster, the quorum is strictly 3 nodes. This guarantees that any two quorums overlap in at least one node containing the latest log entry.
02 Byzantine Fault Tolerance
5 Points
To tolerate up to f arbitrary or malicious Byzantine node failures in an asynchronous distributed network, what is the theoretical minimum total number of nodes N that must be provisioned?
A 2f + 1
B 2f
C 3f + 1
check Correct Key
D 3f + 2

PBFT Canonical Proof (Castro & Liskov):

In Byzantine environments where nodes may send conflicting messages or simply drop requests, you must distinguish between non-responsive nodes and malicious liars. The system requires N >= 3f + 1 to ensure non-faulty nodes reach consensus despite f faulty nodes.
03 Vector Clocks & Causality
5 Points
Given two events e₁ and e₂ with associated vector timestamps V(e₁) = [2, 1, 0] and V(e₂) = [1, 3, 0] across a 3-process architecture, which causal relation accurately classifies the pair?
A e₁ causally preceded e₂ (e₁ → e₂)
B e₂ causally preceded e₁ (e₂ → e₁)
C e₁ and e₂ are concurrent events (e₁ || e₂)
check Correct Key
D Indeterminate without Lamport physical scalar sync

Causal Independence Principle:

Because V(e₁)[0] > V(e₂)[0] (2 > 1) yet V(e₁)[1] < V(e₂)[1] (1 < 3), neither vector strictly dominates the other in all indices. Therefore, the events are mathematically concurrent (e₁ || e₂).
